# Padia Horizon - Sustainable Rice Lab (clone of Field Atlas, Level 11)

This is the Padia-Horizon-branded clone of the Field Atlas Kharif-2025 dashboard. Same data
and features as the main Field Atlas, with the venture name in the header and an 'About Padia
Horizon' card on the Overview.

Deploys to GitHub repo **Field-Atlas-Clone**. To publish, run the git command your assistant
gave you from this folder (it uploads everything and force-mirrors the repo).
